# Задание 1
## Задача 1.9
### Текст задачи
Измените сущность Студент из задачи 1.5.6. Необходимо гарантировать, что добавлять Студенту можно только оценки в диапазоне от 2 до 5, при этом у Студента всегда можно узнать список оценок. Продемонстрируйте на примерах, что нет способа задать Студенту некорректную оценку.
### Алгоритм решения
В классе `Student` метод `setMarks()` проверяет, что массив оценок не равен `null`, а каждая оценка находится в диапазоне от 2 до 5. Метод `setMark()` проверяет новую оценку перед изменением массива. При некорректных данных выбрасывается `IllegalArgumentException`. Метод `getMarks()` возвращает копию массива оценок.

# Задание 2
## Задача 2.3
### Текст задачи
Разработать сущность ТелефонныйСправочник, которая будет использоваться для создания справочника со списком телефонов и имён, с целью поиска телефона по имени. Будем считать достаточным хранение пар телефон — имя, например «89003337788 — Вася». Состояние сущности описывается набором пар «телефон — имя», причем телефон и имя являются строками. В целях упрощения задачи будем считать, что одному имени всегда соответствует один телефон, и один телефон соответствует одному имени. Реализовать добавление и изменение контакта, удаление контакта, получение телефона по имени, получение строкового представления справочника, проверку наличия имени или телефона, получение количества контактов, получение массивов пар, телефонов и имён, а также поиск имён по началу строки.
### Алгоритм решения
В классе `YelowPages` пары хранятся в `HashMap`, где ключом является имя, а значением — телефон. Методы класса добавляют и удаляют пары, находят телефон по имени, проверяют наличие имени или телефона, возвращают количество контактов и массивы данных. Метод `findNamesStartingWith()` находит имена по заданному началу строки. В `Main` создаются контакты и вызываются методы справочника.

# Задание 4
## Задача 4.4
### Текст задачи
Необходимо продумать структуру и организацию следующих геометрических фигур: круг, квадрат, прямоугольник и треугольник. Круг задаётся точкой координат центра и радиусом. Для каждой фигуры обязательно должна быть возможность рассчитать её площадь.

Создан абстрактный класс `Figure` с методом `getArea()`. Классы `Circle`, `Square`, `Rectangle` и `Triangle` наследуются от него и рассчитывают площадь соответствующей фигуры. В `Main` создаются фигуры и выводятся их площади.
